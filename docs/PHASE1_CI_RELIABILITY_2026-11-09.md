## تغييرات هذه الدفعة
1. **Android Debug:** فصل تجهيز الـSPA والأصول والتحقق منها عن تجميع Gradle. إعادة المحاولة مرتين فقط عند أخطاء تنزيل عابرة (429، 5xx محددة، انقطاع/مهلة الاتصال) مع حفظ سجل كل محاولة. أخطاء الكود والتجميع تفشل فورًا ولا يُعاد تجهيز محتوى المصحف والكتب.
2. **Gradle:** تخزين توزيعة الـwrapper المقيّدة بالإصدار على GitHub Actions لتقليل التنزيلات المتكررة.
3. **Windows:** تخزين ملف Electron 39.0.0 في كاش مستقل وإعادة محاولة `npm install` عند أخطاء الشبكة العابرة فقط، دون إعادة محاولة فشل إنشاء EXE نفسه.
4. **Android 1.0.13:** تقاعد ناشر الإصدار القديم الذي يستخدم وسمًا ثابتًا؛ يبقى GitHub Release المنشور دون تغيير. الإصدار القادم يتطلب رقمًا ووسمًا جديدين بعد اعتماد المستخدم.
5. **الاختبارات:** اختبارات ثبات للـworkflows والقيود على إعادة المحاولة والنشر.

## اقتراحات الخطوط للموافقة قبل التنفيذ
- الاعتماد الحالي لواجهة Android: **IBM Plex Sans Arabic** محليًا، مع توفر **Cairo** و**Noto Kufi Arabic** و**Amiri** في حزمة الخطوط.
- يوجد اختلاف بين `AGENTS.md` (Cairo للعناوين) و`src/styles.css` و`src/rihab-daylight.css` (IBM للعناوين والنصوص).
- مقترح **غير مطبّق**: استخدام Cairo بوزن 700 للعناوين فقط، والإبقاء على IBM للنصوص، وتحسين الحد الأدنى للحجم على الشاشات الصغيرة بعد اختبار التفاف النصوص.
- **يُمنع تعديل** خط حفص العثماني وصور صفحات المصحف والخطوط الأصلية المطبـوعة في الكتب دون اعتماد مستقل.

## عناصر لم تُنجز بعد
- تمرير GitHub Actions بعد فتح PR؛ نجاح الفحوص الفعلية ليس مُثبتًا وقت كتابة هذه الوثيقة.
- إصلاح جودة عرض الصفحات والتكبير والتمرير والذاكرة في المرحلة الثانية.
- اختبار الأجهزة الحقيقية كما في [#57](https://github.com/Ahmedmadni/sufi-whispers/issues/57).
- اعتماد خط الواجهة بصريًا على الشاشات المختلفة.
- اعتماد المستخدم وتحديد إصدار جديد (مقترح `1.0.14`، `versionCode=15`) ثم إصدار APK/AAB موقعين ورفع رابط جديد.

## شروط الدمج
- مراجعة PR، نجاح `bun run test` و`bun run typecheck` و`bun run test:integrity`.
- إن أمكن، نجاح Android Debug وWindows داخل CI، والتحقق من أن retries لا تخفي أخطاء غير شبكية.
- عدم تغيير `com.rihabalkhaliliyya.app` أو شهادة التوقيع أو أصول المصحف.
- **لا دمج إلى `main` ولا إصدار Android جديد قبل الاعتماد النهائي.**
