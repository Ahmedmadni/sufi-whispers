# رحاب الخليلية — تدقيق Android 1.0.17 (18) وتوحيد الواجهة

**التاريخ:** 23 نوفمبر 2026 · **الفرع المستهدف:** `main`

## العطل المؤكد

في نسخة 1.0.16 كان أول سطر خاص بتهيئة Android داخل `mobile/main.tsx` يحتوي `\\n` حرفيًا بعد تعليق سطري، بدل سطر جديد فعلي. أدى هذا إلى تحويل إضافة `rihab-android` وتعريف `mount` إلى جزء من التعليق؛ ما يعرض تشغيل React على Android للفشل، ويمنع تنسيقات الجهاز الأفقي من العمل. لم تكتشف الاختبارات السابقة ذلك لأنها كانت تبحث عن النص المصدر دون إثبات قابليته للتنفيذ.

## ما تغير في 1.0.17

1. فصل التعليق عن `document.documentElement.classList.add("rihab-android");` وعن تعريف حاوية React بأسطر تنفيذ حقيقية.
2. إضافة اختبار انحدار يستلزم أن تظهر عبارتا التهيئة وتعريف `mount` على أسطر كود فعلية، بدل أن تكونا تعليقًا أو نصًا مهربًا.
3. إضافة بوابة في `scripts/verify-mobile-bundle.mjs` تفحص **JavaScript المترجم** وتمنع إنتاج الحزمة إذا لم يحتوِ على إضافة صنف Android الفعلي. هذا يشمل بناء Debug وSigned Release لأن كلاهما يشغّل `mobile:build`.
4. الإبقاء على `android:screenOrientation="fullUser"` في `MainActivity` بعد `cap sync android`: يدعم الهاتف والتابلت رأسيًا وأفقيًا عند تشغيل التدوير التلقائي في الجهاز.
5. بقاء CSS الخاص بالتابلت الرأسي (`min-width: 641px`) والأفقي (`min-width: 540px`) وفصل الهيرو إلى عمودين، مع تنسيق الأجهزة القصيرة وشريط تنقل وعناصر تحكم الورد والقارئ.
6. زيادة إصدار الحزمة إلى `1.0.17 (18)` لاستبدال 1.0.16 بتحديث عادي مع نفس `applicationId` وalias التوقيع ونفس شهادة الإصدار؛ إضافة ناشر مستقل `v1.0.17-android-rc1` بعد نجاح جميع بوابات الجودة على SHA واحد.
7. تقييد ناشر 1.0.16 التاريخي إلى SHA الأصلي لتجنب إصدارات قديمة/مكررة بعد الرفع.

## أصول لا يجوز تغييرها

- صورة الشيخ المعتمدة كاملة بنصها المصحح: **محمد محمد أبو خليل**، ونقطة الخاء الصحيحة.
- خط المصحف وصوره الأصلية **604 صفحة**، وكتب القراءة الممسوحة **1040 صفحة**، وصوت الحزبين الأصليين.
- ألوان الواجهة المعتمدة الزمردي والذهبي والعاجي؛ **Cairo** للعناوين و**IBM Plex Sans Arabic** للنصوص، مع الحفاظ على خطوط المصحف والكتب.

## ملاحظات القبول

- نجاح GitHub Actions للبناء وفتح الملف الموقّع لا يساوي اختبار UX على أجهزة فعلية؛ يلزم تدوير جهاز أو محاكي Android في كل المقاسات أعلاه، مع اختبار فتح التطبيق من نقطة البداية.
- أثناء التدوير اختبر تشغيل الصوت بلا توقف غير مبرر، وحفظ موضع القراءة، والفهرس، ونوافذ الأدوات، والتنبيهات واستعادة نسخة محلية.
- لا تنشر إصدار المتجر قبل التأكد من اختبار الترقية فوق 1.0.16 **دون فقد بيانات التطبيق**.
- `fullUser` يحترم قفل التدوير في نظام Android؛ ينبغي تفعيل التدوير التلقائي لاختبار الانتقال للأفقي.
