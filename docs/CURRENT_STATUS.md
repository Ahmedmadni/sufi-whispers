## ما تعالجه المرحلة 22

- تثبيت إصدار Bun في CI عند 1.4.3 المعتمد بآخر Build ناجح.
- استخدام إصدار Capacitor الدقيق 8.5.3 الذي نجح في بناء 11 أكتوبر، دون القبول التلقائي بأي تحديث 8.x أثناء تجهيز Android.
- إضافة بوابة إصدار عامة: `RELEASE_BUILD=1` يتطلب `QURAN_EXPECTED_SHA256` مرجعيًا صحيحًا للنص القرآني، ويفشل عند الغياب أو عدم المطابقة.
- تحديث الوثائق التي كانت تزعم أن بناء APK لم ينجح.

> ملاحظة: لم تُضف حزم Capacitor بعد إلى `package.json` و`bun.lock` في المستودع لأن اعتماديات أندرويد كانت تُثبت خلال عملية البناء؛ يستمر تثبيتها محليًا بإصدارات دقيقة. الحفظ الكامل لمشروع `android/` وتوقيع التطبيق مطلوبان قبل Release.

## بوابات الإطلاق المفتوحة

1. **P0 سلامة النص:** الحصول على بصمة SHA-256 الأصلية لملف Hafs JSON من جهة موثوقة مستقلة، ثم تشغيل `RELEASE_BUILD=1` واختبار ذلك في CI.
2. **P0 تجربة Android:** تثبيت التطبيق على هاتف فعلي، وضع طيران، تنقل المصحف وجميع الكتب والأذكار، الصوت، الاستعادة، الذاكرة.
3. **P0 نسخة Release:** اعتماد `applicationId`، حفظ مفاتيح التوقيع بأمان، توقيع APK وAAB واختبار التحديث وعدم فقدان البيانات.
4. **P1 الأدوات:** تثبيت الاعتماديات بقفل إصدار محفوظ، وتتبع مصدر Android native، وأرقام `versionCode/versionName`.
5. **P1 الأذكار:** تصحيح الاعتماد على أوقات 04:00 و15:00 و18:00 التقريبية؛ تحديد أوقات الفجر والعصر والمغرب حسب مدينة/تاريخ أو بإدخال قابل للتعديل مع توضيح المصدر.
6. **P1 بيانات المستخدم:** تصدير/استعادة نسخة احتياطية للعدّادات ومواضع القراءة.
7. **P2 التوزيع:** إصدار GitHub Release دائم بدل Artifact تنتهي صلاحيته بعد 7 أيام، ثم المتجر إن كان مطلوبًا.

## تعليمات البناء

```sh
bun install --frozen-lockfile
bun run test:integrity
bun run test
bun run typecheck
bun run build
# offline Quran / books fonts must be prepared as in android-debug.yml
bun run mobile:android:apk
```

**لإصدار عام فقط** بعد اعتماد البصمة وتوفير الملفات الأصلية:
```sh
RELEASE_BUILD=1 QURAN_EXPECTED_SHA256=<verified-publisher-sha256> bun run mobile:build
```

هذا الفحص ليس عملية توقيع Android، ولا ينبغي تسويق APK تجريبي على أنه نسخة إصدار عام.

## المرحلة 33 — قارئ الكتب بملء الصفحة والفهارس الواقعية

- دعم قارئ الكتب المصورة السبعة وقارئ `جامع النفحات` بصيغة PDF بوضع قراءة
  يغطي نافذة التطبيق على أندرويد والمتصفح، مع زر `ملء الشاشة` / `الخروج من ملء الشاشة`
  واضح حتى لو لم يدعم Android WebView واجهة Fullscreen API.
- اتجاه تقليب الكتب أصبح موافقًا للمصحف المطبوع: سحب **يمين = التالية**،
  وسحب **يسار = السابقة**، وكذلك سهم لوحة المفاتيح إلى اليمين = التالية.
- إضافة `فهرس الكتاب المختصر` قابل للنقر في كل كتاب: الفهرس الأصلي لملفات PDF
  إن كان مُضمّنًا بالمصدر، وإلا محطات تقليب مبيّنة كمواضع صفحات فقط،
  من دون اختلاق أسماء قصائد أو فصول خاصة بكتب المديح.
- تسجيل عناوين PDF الأصلية في ملفات manifest للكتب المصوّرة أثناء البناء؛
  لا تعديل على الصور المصدرية أو صفحات المصحف الـ604 أو كتب الأوفلاين الـ1040.
- اختبارات انحدار `tests/book-reader-experience.test.ts` للاتجاه والإغلاق
  وفهارس الكتب ومحتوى APK. القبول النهائي لتجربة اللمس يتم بعد اختبار APK
  على هاتف Android فعلي.

## المرحلة 34 — مراجع فهرس جامع النفحات الأصلية والخط العربي

- تبيّن بالفحص المباشر لـ`public/book.pdf` أن الملف **432 صفحة**،
  وأن الفهرس المطبوع الحقيقي يظهر في صفحات **425–431**، وملف PDF
  **لا يضم bookmarks رقمية جاهزة**، كما أن استخلاص بعض عناوينه العربية
  مشوّه بسبب ترميز خطوط PDF القديمة.
- أمّن البرنامج `scripts/generate-nafahat-index.py` مراجع الفهرس الأصلية من
  أرقام صفحاتها ومواضعها المطبوعة: **458 سطرًا مرجعيًا** عبر 7 صفحات؛
  تحفظ مواضعها وبصمة المصدر في `src/data/nafahat-printed-index.json`.
- يعرض `NafahatPrintedIndex` **الصفحات المطبوعة نفسها** بالحروف الأصلية
  دون أي OCR أو إعادة صياغة خاطئة، وكل سطر منها زر شفاف يفتح الصفحة
  المشار إليها. يتضمن تكبير الفهرس لتسهيل القراءة والضغط على الهاتف.
  مقارنة الفهرس بالمصدر وبصمته شرط ضمن اختبارات GitHub.
- أزيل **ربع الكتاب / منتصف الكتاب / ثلاثة أرباع الكتاب** من الفهرس:
  الكتب السبعة الأخرى لا تعرض إلا العناوين الحقيقية عندما يكون
  الفهرس موجودًا ضمن بيانات ملفات PDF الأصلية. لا توجد عناوين
  مختلقة تُقدّم للقارئ على أنها قصائد أو فصول حقيقية.
- استُبدل خط الشريط المتحرك ب`Aref Ruqaa Ink` العربي التراثي،
  محملًا محليًا مع ترخيص OFL ومثبتًا بإصدار المصدر.
  يظل النص نفسه وحركته الهادئة ودعم تقليل الحركة دون تغيير.
- جودة المصحف وملفات القراءة دون إنترنت لا تتغير. أيقونة التطبيق
  والإصدار الموقع رسميًا لا تدخل ضمن هذه المرحلة.
