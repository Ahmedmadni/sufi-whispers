# رحاب الخليلية — مراجعة وتحسين الهوية البصرية (V2)
**9 نوفمبر 2026** — فرع تصميم منفصل: `design/rihab-visual-identity-icons-2026-11-09`

## نتيجة مراجعة الواجهة
1. **شريط التنقل على الهاتف:** أيقونات Lucide قياس 18px وتسميات 10px مع اعتماد لون فقط تقريبًا لتمييز الوجهة. هذا يضعف التعرف البصري خصوصًا في الهاتف الصغير.
2. **شريط الرأس:** شعار الجمعية أصيل ومناسب؛ أيقونة الإعدادات 18px وأزرارها 40px. روابط الأقسام الأساسية كانت `hidden` بلا إظهار على شاشة سطح المكتب، رغم اختفاء شريط التنقل السفلي عند `lg`.
3. **المكتبة:** زر البحث ليس واضحًا بما يكفي كإجراء، والبطاقات لا تملك هوية ورقية مميزة؛ عناوين الكتب تحتاج تباينًا وتسلسلًا بصريًا أفضل.
4. **قرّاء الكتب والمصحف:** أدوات التحكم العائمة والرموز الصغيرة تحتاج وضوحًا أعلى، من دون تغيير الصفحات المطبوعة أو الخط العثماني أو مساحة الصورة.

## التعديلات المنفذة
- **هوية الألوان:** اعتماد زمردي داكن `#193b30`، نحاسي ذهبي هادئ `#d4b273`، عاجي `#fffdf7` وحدود لينة `#d7ddcf`. هذه تخص الواجهة فقط.
- **أيقونات موحدة:** 22px للسطر السفلي، strokeWidth 2.25 لرموز Lucide الأساسية، حاويات أيقونات 40×35px وتسميات لا تقل عن 11px لمعظم المقاسات.
- **حالة التنقل:** تباين اللون *مع* خلفية وحاوية ممتلئة ومؤشر سفلي وحالة تركيز بلوحة المفاتيح. تبقى وجهات التنقل الخمس وترتيبها كما هي.
- **الذكر:** أيقونة السبحة الحالية ما زالت نفسها (شكلها الخاص)، لكنها أكثر وضوحًا بحاوية 51px وتباين محسّن.
- **الرأس:** شعار الجمعية الأصلي محفوظ، زر الإعدادات وفيسبوك 44px، وفتح روابط الرأس المكتبي ابتداءً من 1024px.
- **المكتبة:** بحث كبير مع علامة واضحة وعدد الكتب، بطاقات فاتحة بحدود وظلال هادئة وعنوان واضح وعبارة «قراءة الكتاب». صور الأغلفة الأصلية في أماكنها.
- **الصفحة الرئيسية:** بطاقات الروابط السريعة ذات أيقونة بارزة ومقاس موحد، وبطاقات الكتب المختارة بنفس هوية المكتبة.
- **قراءة الكتب:** تحسين تباين أزرار الفهرس وملء الشاشة، وتحسين حدود رموز أدوات المصحف؛ **دون تعديل صورة الصفحة أو مخطوطها**.
- **إتاحة الوصول:** الحد الأدنى للأزرار المهمة 44–68px حسب الموضع، حالات `focus-visible`، واحترام `prefers-reduced-motion`.
- **التقنية:** ملف `src/rihab-identity.css` مستقل يُحمّل آخرًا على الويب وداخل APK عبر `mobile/main.tsx`، دون أي خط أو صورة خارجية جديدة.

## القيود المحفوظة
- **شعار الجمعية والهوية المصوّرة:** لم تُستبدل ملفات `src/assets/rihab-logo-clean.png` أو صور الشيخ والقبة أو `public/icon-192.png` و`public/icon-512.png`.
- **خطوط المشروع:** يبقى `Cairo` للعناوين، `IBM Plex Sans Arabic` للنصوص، و`UthmanicHafs` للآيات.
- **المصحف والكتب:** لا تعديل لنصوص أو صور المصحف أو ملفات PDF أو صفحات الكتب المصورة أو فهارسها.
- **Android:** لا تغيير للـ `applicationId` ولا التوقيع ولا إشعارات الورد ولا ملفات المستخدم ولا النسخة المنشورة.
