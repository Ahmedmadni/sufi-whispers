# رحاب الخليلية — دليل الهوية البصرية V1

## الفكرة
حافظنا على الصور الأصلية: القبة الخضراء، صورة الشيخ، الشعار، وأغلفة الكتب.
أضفنا نظام عرض بصري يعتمد على الأخضر الداكن والذهبي، مع زخارف هندسية
خفيفة مصنوعة بـ CSS دون تحميل مكتبات رسوم إضافية.

## المكونات التي شملها التحسين
- **HomeHero**: تدرجات إضاءة، زخارف خفيفة، بطاقة تعريف بالهوية، وتحسين زمن ظهور المشهد.
- **Library**: غلاف عنوان جديد، أغلفة ذات عمق بصري وتأثير انعكاس للمرور بالفأرة فقط،
  إصلاح دلالة التصنيفات لتصبح مجموعة أزرار ضغط بدل tabs غير مكتملة.
- **Home selected books**: نفس مكون الغلاف الذي يستعمل التحميل الكسول؛
  اختلافات الترتيب لا تغير مصدر الصورة الأصلية.
- **Dhikr**: سبحة دائرية تتضمن تقدم الذكر الجاري مع الحفاظ على العد اليدوي.
- **Mushaf / PDF**: تحسين حدود صفحات القراءة والفواصل دون تغيير الرسم العثماني أو ملفات الكتب.
- **Mobile nav**: إبراز رابط الصفحة الحالية ومراعاة مساحات اللمس.

## الأداء والوصول
- مؤثرات الغلاف ثلاثية الأبعاد تعمل فقط عند `hover: hover` و `pointer: fine`.
- جميع المؤثرات الزخرفية خاضعة لوسائط `prefers-reduced-motion`.
- الحفاظ على وضوح النص وتباينه في الوضعين الداكن والفاتح.
- لا توجد صور مستوردة من خارج المستودع؛ إضاءة الهيرو والخلفيات مبنية باستخدام CSS.
- ملفات الأنماط الجديدة `src/visual-experience.css` محمّلة لكل من SSR والواجهة المحمولة
  عبر `src/routes/__root.tsx` و `mobile/main.tsx`.

## مراجعة يدوية قبل اعتبار التحديث إنتاجيًا
1. فتح الصفحة الرئيسية على أجهزة صغيرة وكبيرة والتحقق من عدم حجب النص بسبب الصورة.
2. اختبار تصنيفات الكتب، جميع الأغلفة الأصلية والمعاينات.
3. الضغط المتكرر على عداد الذكر والتأكد من صحة القيمة وحلقة التقدم.
4. فتح المصحف وملفات PDF في الوضعين النهاري والليلي.
5. تفعيل "تقليل الحركة" على Android/Windows والتأكد من اختفاء الحركة الزائدة.
6. اختبار الاستخدام من لوحة المفاتيح وقراء الشاشة.
7. `bun run test` و `bun run typecheck` و `bun run build`،
   بالإضافة إلى `bun run mobile:build` بعد توفير ملفات Lovable الأصلية.

## الفصل بين المسؤوليات
تغييرات العرض هذه لا تعني اكتمال تطبيق Android الأصلي أو إنتاج APK.
هي تعمل فوق طبقة بناء Android التحضيرية المدمجة في المرحلة السابقة.
