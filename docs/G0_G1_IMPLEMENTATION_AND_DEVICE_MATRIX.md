## ما **لا** يعتبر مكتملًا بعد

**G0 يتطلب جهازًا حقيقيًا**؛ لا يمكن استنتاج نجاح تكبير إصبعين أو ترقية ملفات Release من فحص TypeScript أو محاكي DOM وحده. لا نُطلق ادعاء «جاهز نهائيًا» قبل المصفوفة أدناه.

| الجهاز | السيناريو | التسجيل المطلوب | الحالة |
|---|---|---|---|
| Android هاتف 360×800 تقريبًا | وضع طيران، فتح الكتب الثمانية + المصحف | نموذج الهاتف/Android، لقطات صفحات وصور | ⏳ يحتاج تنفيذ |
| Android هاتف صغير ≤360px | الضغط المفرد/المزدوج، pinch حول المركز، pan، العودة | فيديو قصير + عدد حالات تقليب خاطئة | ⏳ |
| Android أفقي | تكبير ×4 + ملء الشاشة + خروج دون حجب الزر | لقطات وإثبات زر الرجوع | ⏳ |
| Windows x64 | مُثبّت EXE، إغلاق/فتح، مراجعة الكتب دون اتصال | إصدار Windows، نجاح/فشل كل كتاب | ⏳ |
| Windows لوحة لمس / ماوس | Ctrl+wheel، عجلة داخل الصفحة، اختصارات | فيديو أو خطوات معاودة | ⏳ |
| Web (متصفحات Chromium/Firefox) | أوامر لوحة المفاتيح، RTL والتباين | المتصفح/الإصدار ولقطات | ⏳ |
| Android ترقية موقّعة | تحديث من 1.0.5 والرجوع لمواضع القراءة/الأذكار | قبل/بعد وحفظ البيانات | ⏳ |

### خطوات إعادة الإنتاج الثابتة

1. افتح «جامع النفحات» ثم «النفحات الخليلية» و«ورد الاستغفار» وكذلك باقي الكتب؛ سجّل أول رقم صفحة ظاهر.
2. اختبر التمرير داخل صفحة طويلة، والسحب من منتصف الصفحة، ثم من الحافة السفلى؛ لا يُغيَّر رقم الصفحة إلا عند الحافة.
3. كبّر حتى 400% ثم اسحب أفقيًا ورأسيًا داخل الصفحة؛ لا يُغيّر السحب الأفقي صفحة مكبرة.
4. اضغط مرة لطيّ الأدوات ومرة أخرى لإعادتها؛ اضغط مرتين للتكبير ثم مرتين لإعادة الحجم.
5. ادخل وضع ملء الشاشة مع الشريط مخفيًا: جرّب زر «إظهار الأدوات»، وزر «الخروج»، ثم `Escape` على Windows.
6. اقفز عبر الفهرس، اقفل البرنامج وافتحه من جديد، وتحقق من الاستئناف وعدم تلف الكتاب.
7. كرر دون إنترنت، وبالاتجاه الأفقي والعمودي، واختبر نموذج استيراد نسخة بيانات 1.0.5.

### أوامر CI المطلوبة

```bash
bun install --frozen-lockfile
bun run test
bun run typecheck
bun run test:integrity
bun run build
node --test desktop/tests/*.test.cjs
```

**بوابة الخروج:** اكتمال CI لا يغلق #49. بعد نجاح اختبار الأجهزة وتدقيق المصحف والكتب يمكن اعتماد نسخة 1.0.6 ثم الانتقال إلى وضع القراءة المتواصلة G2؛ لا تُدمج فهرسة OCR قبل مراجعة مصادرها.

**قيود تقنية:** قارئ PDF يعيد الرسم عند تغيير الحجم، وقد تحتاج خاصية التمركز عند موضع اللمس إلى تصحيح حسب المتصفح؛ يُفضّل قياس ذلك على جهاز فعلي وليس افتراض الدقة.
