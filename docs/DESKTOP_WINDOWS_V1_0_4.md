# رحاب الخليلية — Windows Desktop (1.0.4)

هذه النسخة برنامج مستقل لويندوز x64 وليست مجرد رابط للموقع. عند تثبيتها، تعمل **صفحات المصحف الـ604**، و**صفحات الكتب السبعة الـ1040**، و«جامع النفحات» PDF وفهرسه المطبوع، والخطوط العربية دون اتصال. التكبير المتدرج حتى 400% على صور الكتب والـPDF باستخدام إصبعين (على الأجهزة ذات الشاشة اللمسية)، أو Ctrl مع عجلة الماوس/لوحة اللمس داخل القارئ.

## التنزيل والتشغيل

عند نجاح [Windows Desktop Offline Installer](https://github.com/Ahmedmadni/sufi-whispers/actions/workflows/windows-desktop.yml)، افتح [إصدار Windows 1.0.4](https://github.com/Ahmedmadni/sufi-whispers/releases/tag/v1.0.4-windows-rc1) لتحميل ملف `Rihab-Al-Khaliliyya-Windows-Setup-1.0.4-x64.exe` وبصمة SHA-256.

يُشغَّل المثبّت على Windows x64؛ لا يحتاج المستخدم إلى تثبيت Python أو Node أو Android Studio. يحتفظ البرنامج بمواضع القراءة داخل بيانات مستخدم Windows. يمكن استخدام Ctrl مع + و- و0 للتحكم في تكبير واجهة البرنامج.

**الحالة الأمنية:** إصدار Windows الأول تجريبي وغير موقّع بشهادة Authenticode. قد يُظهر Windows SmartScreen تحذير الناشر غير المعروف؛ لا نوصي بتعطيل الحماية. يحتاج اختبارات تثبيت، وإغلاق، وإزالة، وقراءة فعلية على Windows قبل اعتماد التوزيع الواسع.

## كيف يعمل؟

- مسار بناء وحيد للمحتوى: نفس عملية التحقق من قرآن وكتب Android، ثم Vite standalone.
- Electron يعرض محتوى البرنامج من خادم محلي **127.0.0.1** عشوائي المنفذ، دون استقبال اتصالات الشبكة الخارجية.
- تعطيل Node.js في صفحات التطبيق وعزل سياق Electron وتفعيل sandbox وحظر صلاحيات المتصفح والمواقع الخارجية غير المصرح بها.
- منع تجاوز مجلد الأصول عبر روابط الملفات أو الروابط الرمزية، ودعم HTTP Range لملفات PDF.
- الشيفرة المصدرية لبرنامج الكمبيوتر في `desktop/`، وخط البناء في `.github/workflows/windows-desktop.yml`.
- برنامج الكمبيوتر **لا يفعّل إشعارات Android المحلية**؛ هذه الخاصية مخصصة لتطبيق الهاتف.

## شروط قبول النسخة

أن ينجح بناء Windows على GitHub، وأن تحتوي الحزمة على 604 صفحات مصحف و1040 صفحة كتب وكل الخطوط والملفات، وأن ينجح اختبار الرابط المحلي وحماية المسارات، ثم اختبار التشغيل على Windows فعلي. إلى ذلك الوقت، لا تُسمَّى النسخة «معتمدة نهائيًا».

اختبار الخادم: `node --test desktop/tests/server.test.cjs`. اختبار الحزمة: `node desktop/scripts/verify-bundle.cjs dist-mobile`.
